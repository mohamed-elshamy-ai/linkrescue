What it does

LinkRescue keeps a list of links you care about. Each check tells you if a link is still fine, was redirected, is broken, or the page text changed from your saved copy. It stores the text locally so you can search it even after the page is gone, and for dead links it looks up an Internet Archive copy.

Install

Windows

Install Python 3.9+ from python.org (tick "Add python.exe to PATH"), then in PowerShell:
py -m pip install git+https://github.com/mohamed-elshamy-ai/linkrescue
py -m pip install .
linkrescue import bookmarks.html
linkrescue check
Untested. Should work (standard library only). Only tested on Linux.

macOS

Python 3.9+ (brew install python or python.org), then in Terminal:
python3 -m pip install git+https://github.com/mohamed-elshamy-ai/linkrescue
pip install .
linkrescue import bookmarks.html
linkrescue check
Untested. Should work. Only tested on Linux.

Linux

Python 3.9+ is usually installed. In a terminal:
python3 -m pip install --user git+https://github.com/mohamed-elshamy-ai/linkrescue
pip install .
linkrescue import bookmarks.html
linkrescue check
Tested. Tested on Linux (Python 3.10).

How it worksإزاي بيشتغل

  1. You add links or import your bookmarks.
  2. LinkRescue fetches each page and keeps the main text (menus and footers removed).
  3. On each check it compares the page with your saved copy: 404 or a not-found page is BROKEN, a redirect to a home page is MOVED, a big text difference is CHANGED.
  4. For dead links it asks the Internet Archive for the closest copy.
  5. You search your saved text or run diff to see what changed.
الشرح بالعربي

بتضيف لينكات أو بتستورد الـ Bookmarks. الأداة بتفتح كل صفحة وبتحفظ النص الأساسي على جهازك. كل مرة تفحص بتقارن بنسختك: 404 يعني BROKEN، تحويل للصفحة الرئيسية يعني MOVED، واختلاف كبير في النص يعني CHANGED، وللينكات الميتة بتدور على نسخة في Internet Archive. تقدر تدور جوه النصوص المحفوظة وتشوف الفرق. الصفحات اللي بتعتمد على JavaScript مش بتتقرا كويس.

Honest limits

  • No JavaScript rendering: script-built pages may have little or no saved text.
  • Text extraction is a simple rule, not Trafilatura. Menus may leak in or content may be lost on some sites.
  • Only text is saved, not the page layout or images.
  • The archive lookup needs internet access and does not submit pages to the archive.
  • Command line only. No extension and no built-in scheduler (use cron or Task Scheduler).
